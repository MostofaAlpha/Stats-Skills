# Stats-Skills

A repository of AI-agent skills for statistics, econometrics, and research
methodology.

## Skills

| Skill | File | Description |
|---|---|---|
| Statistics, Econometrics & Research Expert | [`skill.md`](skill.md) | Expert-level specification covering method selection, assumptions and identification assessment, causal-inference discipline, statistical computing, error detection, interpretation, and reproducible-research standards. |
| GraphSkill — Statistical Visualization & Analytics Expert | [`graphskill.md`](graphskill.md) | Expert-level specification for graph selection, statistical integrity of visualizations, graph interpretation, research-grade figures, dashboards, and R / Python / Power BI / DAX implementation. |

## Usage

Point your agent's skill-activation prompt at the relevant skill file —
[`skill.md`](skill.md) for statistical/econometric/research tasks,
[`graphskill.md`](graphskill.md) for visualization and analytics tasks (the
two compose well for end-to-end analysis) — and instruct the agent to read
the file before answering. Each file is self-contained: it defines the
expertise domains, decision-making frameworks, workflows, and quality rules
the agent must follow.
